Tapix ships a standalone Livewire component that renders the full import wizard. Use it to embed the wizard in any Blade view outside of Filament.

## Layout Requirements

The wizard uses Filament actions and icons, so your layout must include Filament's styles and scripts:

```blade [layouts/app.blade.php]
<head>
    @filamentStyles
    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
<body>
    {{ $slot }}
    @filamentScripts
</body>
```

If you're using a Filament panel, these are already included automatically. Otherwise, running `php artisan tapix:install` (once) and adding `tapix:upgrade` to your composer scripts (see [Installation](/getting-started/installation)) handles publishing the required JS/CSS.

## Supported File Types

The upload step derives the file types it accepts from the readers registered in `tapix.readers` -- CSV, TXT, and XLSX out of the box. The file picker's `accept` attribute, the upload validation rule, and the wizard copy all read from the same source, so registering a [custom reader](/features/file-formats#custom-readers) makes that extension selectable without touching the component.

Uploads are validated by extension rather than MIME type: readers are chosen by extension anyway, and content sniffing is unreliable here -- many genuine XLSX files are reported as `application/zip`, which a `mimes:xlsx` rule would reject. A file with an unregistered extension is rejected with a message naming the accepted types.

## Basic Usage

```blade
<livewire:tapix.wizard
    :importer-class="App\Importers\ContactImporter::class"
    :return-url="route('contacts.index')"
    :sample-file="asset('samples/contacts.csv')"
/>
```

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `importerClass` | `string` | Yes | Fully qualified class name of the importer. |
| `returnUrl` | `string` | No | Relative URL to redirect to on cancel. Absolute and protocol-relative URLs are rejected. |
| `sampleFile` | `string` | No | URL to a sample file. Displays a download link in the upload step. Its extension must have a registered reader. |

## Events

| Event | Payload | Description |
|-------|---------|-------------|
| `onUploadCompleted` | `storeId, rowCount, columnCount` | Fired after the file has been parsed and stored. |
| `import-started` | -- | Livewire event dispatched when the import execution begins. |
