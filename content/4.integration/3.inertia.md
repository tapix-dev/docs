Tapix provides an import wizard for Inertia.js applications in both Vue 3 and React 19. The `tapix/inertia` package ships the backend API routes, TypeScript types (`@tapix/core`), and framework component libraries (`@tapix/vue`, `@tapix/react`).

::note
Install the package first with `composer require tapix/inertia` and run `php artisan tapix:install`. See the [Installation](/getting-started/installation) page for the full flow.
::

## Setup

::tabs
  ::tab{label="Vue"}
  **1. Configure Vite aliases** so your bundler can resolve the components:

  ```js [vite.config.js]
  export default defineConfig({
      resolve: {
          alias: {
              '@tapix/vue': '/vendor/tapix/inertia/resources/js/vue/src',
              '@tapix/core': '/vendor/tapix/inertia/resources/js/core/src',
          },
      },
  });
  ```

  **2. Render the wizard from a page.** `TapixWizard` is a plain Vue component -- render it from any Inertia page and pass the props through from your controller:

  ```vue [resources/js/Pages/Import.vue]
  <script setup>
  import { TapixWizard } from '@tapix/vue'

  defineProps({ importerClass: String, apiBaseUrl: String })
  </script>

  <template>
      <TapixWizard :importer-class="importerClass" :api-base-url="apiBaseUrl" />
  </template>
  ```
  ::

  ::tab{label="React"}
  Requires React 19.

  **1. Configure Vite aliases** so your bundler can resolve the components:

  ```js [vite.config.js]
  export default defineConfig({
      resolve: {
          alias: {
              '@tapix/react': '/vendor/tapix/inertia/resources/js/react/src',
              '@tapix/core': '/vendor/tapix/inertia/resources/js/core/src',
          },
      },
  });
  ```

  **2. Render the wizard from a page.** `TapixWizard` is a plain React component -- render it from any Inertia page and pass the props through from your controller:

  ```tsx [resources/js/Pages/Import.tsx]
  import { TapixWizard } from '@tapix/react'

  export default function Import({ importerClass, apiBaseUrl }) {
      return <TapixWizard importerClass={importerClass} apiBaseUrl={apiBaseUrl} />
  }
  ```
  ::
::

## Standalone Component

You can also use the wizard as a standalone component in any page.

::tabs
  ::tab{label="Vue"}
  ```vue
  <script setup>
  import { TapixWizard } from '@tapix/vue'

  function onComplete(results) {
      console.log(results) // { created: 10, updated: 3, skipped: 1, failed: 0 }
  }
  </script>

  <template>
      <TapixWizard
          importer-class="App\Importers\ContactImporter"
          :api-base-url="$page.props.appUrl"
          @complete="onComplete"
      />
  </template>
  ```
  ::

  ::tab{label="React"}
  ```tsx
  import { TapixWizard } from '@tapix/react'

  export function ImportPage({ appUrl }) {
      function onComplete(results) {
          console.log(results) // { created: 10, updated: 3, skipped: 1, failed: 0 }
      }

      return (
          <TapixWizard
              importerClass="App\Importers\ContactImporter"
              apiBaseUrl={appUrl}
              onComplete={onComplete}
          />
      )
  }
  ```
  ::
::

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `importerClass` | `string` | Yes | Fully qualified class name of the importer. |
| `apiBaseUrl` | `string` | Yes | Base URL for API calls (e.g. your app URL). |

In Vue, props are kebab-case (`importer-class`, `api-base-url`); in React they are camelCase (`importerClass`, `apiBaseUrl`).

### Completion callback

The wizard reports the final counts `{ created, updated, skipped, failed }` when the import finishes.

- **Vue:** listen for the `@complete` event.
- **React:** pass an `onComplete` callback prop.

## Composables & Hooks

Both packages export the same primitives for advanced customization (Vue composables / React hooks):

| Vue | React | Purpose |
|-----|-------|---------|
| `useImportWizard` | `WizardProvider` + `useWizardContext` | Main wizard orchestrator -- manages steps, state, and the API client. |
| `useWizardContext` | `useWizardContext` | Access wizard state from nested components. |
| `useReviewTable` | `useReviewTable` | Manages the review step table -- pagination, filtering, corrections, and skipping. |
| `usePolling` | `usePolling` | Generic polling utility for tracking validation and execution progress. |
| -- | `useOptionSearch` | Debounced remote option search for searchable choice cells. |

## API Routes

The package registers API routes under the `/imports` prefix. All routes use `['web', 'auth']` middleware by default.

See the [Configuration](/getting-started/configuration#routes) page for customizing the prefix and middleware.
