Tapix provides a Vue 3 wizard component for Inertia.js applications. The `tapix/inertia` package includes the backend API routes, a Vue component library, and TypeScript types.

## Setup

::steps

### Configure Vite aliases

Add the Tapix package aliases to your `vite.config.js` so your bundler can resolve the components:

```js [vite.config.js]
export default defineConfig({
    resolve: {
        alias: {
            '@tapix/vue': '/vendor/tapix/inertia/resources/js/vue/src',
            '@tapix/core': '/vendor/tapix/inertia/resources/js/core/src',
        },
    },
});
```

### Register the page resolver

Tell Inertia how to resolve Tapix pages alongside your own:

```js [resources/js/app.js]
import { resolveTapixPage } from '@tapix/vue/inertia'

createInertiaApp({
    resolve: (name) => {
        if (name.startsWith('Tapix/')) return resolveTapixPage(name)
        return resolvePageComponent(name, import.meta.glob('./Pages/**/*.vue'))
    },
})
```

## Standalone Component

You can also use the wizard as a standalone Vue component in any page:

```vue
<script setup>
import { TapixWizard } from '@tapix/vue'

function onComplete(results) {
    console.log(results) // { created: 10, updated: 3, skipped: 1, failed: 0 }
}
</script>

<template>
    <TapixWizard
        importer-class="App\Importers\ContactImporter"
        :api-base-url="$page.props.appUrl"
        @complete="onComplete"
    />
</template>
```

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `importerClass` | `string` | Yes | Fully qualified class name of the importer. |
| `apiBaseUrl` | `string` | Yes | Base URL for API calls (e.g. your app URL). |

### Events

| Event | Payload | Description |
|-------|---------|-------------|
| `complete` | `{ created, updated, skipped, failed }` | Fired when the import finishes. |

## Composables

The package exports composables for advanced customization:

| Composable | Purpose |
|------------|---------|
| `useImportWizard` | Main wizard orchestrator -- manages steps, state, and the API client. |
| `useWizardContext` | Access wizard state from nested components. |
| `useReviewTable` | Manages the review step table -- pagination, filtering, corrections, and skipping. |
| `usePolling` | Generic polling utility for tracking validation and execution progress. |

## API Routes

The package registers API routes under the `/imports` prefix. All routes use `['web', 'auth']` middleware by default.

See the [Configuration](/getting-started/configuration#routes) page for customizing the prefix and middleware.
