## Create an Importer

Generate an importer for an existing Eloquent model. `--generate` reads the model's table and creates a field for each column:

```bash [Terminal]
php artisan make:tapix-importer ContactImporter --model=Contact --generate
```

This creates `app/Importers/ContactImporter.php`. A minimal importer looks like this:

```php [app/Importers/ContactImporter.php]
<?php

namespace App\Importers;

use App\Models\Contact;
use Tapix\Core\Fields\ImportField;
use Tapix\Core\Importing\BaseImporter;

final class ContactImporter extends BaseImporter
{
    public function model(): string
    {
        return Contact::class;
    }

    public function fields(): array
    {
        return [
            ImportField::make('name')->required(),
            ImportField::make('email')->rules(['email'])->guess(['e-mail', 'email address']),
            ImportField::make('phone'),
        ];
    }
}
```

Each field key is a model attribute. Tapix auto-maps CSV headers that match a field's key, label, or `guess()` aliases, and users can adjust the mapping in the wizard. See [Defining Importers](/importers/defining-importers) and [Fields](/importers/fields) for the full API.

::note
Without `--model`, the generated class points at a placeholder `\App\Models\Model::class`. Replace it with your model before running an import.
::

## Run Your First Import

::tabs
  ::tab{label="Livewire"}
  Embed the wizard in any Blade view:

  ```blade
  <livewire:tapix.wizard
      :importer-class="App\Importers\ContactImporter::class"
      :return-url="route('contacts.index')"
  />
  ```

  See the [Livewire integration](/integration/livewire) page for all available props.
  ::

  ::tab{label="Filament"}
  Register the `TapixPlugin` in your panel provider:

  ```php [app/Providers/Filament/AdminPanelProvider.php]
  use Tapix\Livewire\Filament\TapixPlugin;

  public function panel(Panel $panel): Panel
  {
      return $panel
          ->plugins([
              TapixPlugin::make()
                  ->discoverImporters(),
          ]);
  }
  ```

  See the [Filament integration](/integration/filament) page for full configuration options.
  ::

  ::tab{label="Inertia"}
  Render the wizard directly in any Inertia page:

  :::tabs
    :::tab{label="Vue"}
    ```vue
    <script setup>
    import { TapixWizard } from '@tapix/vue'

    function onComplete(results) {
        console.log(results) // { created: 10, updated: 3, skipped: 1, failed: 0 }
    }
    </script>

    <template>
        <TapixWizard
            importer-class="App\Importers\ContactImporter"
            :api-base-url="$page.props.appUrl"
            @complete="onComplete"
        />
    </template>
    ```
    :::

    :::tab{label="React"}
    ```tsx
    import { TapixWizard } from '@tapix/react'

    export default function Import({ appUrl }) {
        function onComplete(results) {
            console.log(results) // { created: 10, updated: 3, skipped: 1, failed: 0 }
        }

        return (
            <TapixWizard
                importerClass="App\Importers\ContactImporter"
                apiBaseUrl={appUrl}
                onComplete={onComplete}
            />
        )
    }
    ```
    :::
  :::

  See the [Inertia integration](/integration/inertia) page for Vite config and composables.
  ::

  ::tab{label="Programmatic"}
  Run imports from artisan commands, API endpoints, or scheduled tasks:

  ```php
  use Tapix\Core\Tapix;
  use App\Importers\ContactImporter;

  $manager = Tapix::import(ContactImporter::class);
  $import = $manager->createFromFile('/path/to/contacts.csv', userId: $user->id);
  $mappings = $manager->autoMap($import);
  $manager->validateForReview($import);
  $executionBatchId = $manager->execute($import);
  ```

  See the [Programmatic API](/integration/programmatic) page for the full reference.
  ::
::

## Verify

Make sure a queue worker is running (`php artisan queue:work`). Tapix validates and imports rows in queued jobs.

1. Navigate to the page where you embedded the wizard (or your Filament admin panel).
2. Confirm the import wizard loads and displays the upload step.
3. Upload a small CSV file, review the mapping, and run the import.
4. Check that the rows were created in your model's table.

If the import doesn't progress, see [Troubleshooting](/advanced/troubleshooting).
