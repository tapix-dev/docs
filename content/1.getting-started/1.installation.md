## Requirements

- PHP 8.4 or higher
- Laravel 12 or higher
- A supported database: MySQL, PostgreSQL, or SQLite

## License

Tapix is a commercial package. [Purchase a license](https://tapix.dev) to get your license key, then follow the steps below.

## Installation

::steps

### Add the Tapix repository

```bash [Terminal]
composer config repositories.tapix composer https://composer.tapix.dev
```

### Install the package

:::tabs
  :::tab{label="Livewire"}
  Import wizard UI + Filament v5 plugin. Best for Livewire and Filament apps.

  ```bash [Terminal]
  composer require tapix/livewire
  ```

  After installing, import the Tapix theme in your main CSS file. This pulls in Filament's color palette (required for the wizard's `primary`/`danger`/`success`/`warning` classes) and registers Tapix views as a Tailwind v4 source:

  ```css [resources/css/app.css]
  @import '../../vendor/tapix/livewire/resources/css/theme.css';
  ```
  :::

  :::tab{label="Inertia"}
  Import wizard for Inertia.js. Best for Vue / React apps using Inertia.

  ```bash [Terminal]
  composer require tapix/inertia
  ```

  After installing, register the Tapix package as a Tailwind v4 source so the wizard's utility classes are included:

  ```css [resources/css/app.css]
  @source '../../vendor/tapix/inertia/resources';
  ```

  Then configure Vite aliases and render the wizard. See the [Inertia integration](/integration/inertia) page for Vue and React setup.
  :::

  :::tab{label="Core"}
  Engine only -- no UI. Best for API endpoints, CLI commands, or custom frontends.

  ```bash [Terminal]
  composer require tapix/core
  ```
  :::
:::

When Composer prompts for credentials, enter:

- **Username:** your email (used during purchase)
- **Password:** your license key

Your credentials are saved in Composer's `auth.json` for future updates.

::tip
**CI / non-interactive environments:** pre-configure credentials so Composer doesn't prompt:
```bash [Terminal]
composer config http-basic.composer.tapix.dev your-email@example.com your-license-key
```
Do not commit `auth.json` to version control.
::

### Publish the configuration

```bash [Terminal]
php artisan vendor:publish --tag=tapix-config
```

This creates `config/tapix.php`. See the [Configuration](/getting-started/configuration) page for all available options.

### Run the Tapix installer

:::tabs
  :::tab{label="Livewire / Inertia"}
  ```bash [Terminal]
  php artisan tapix:install
  ```

  The installer prompts to run pending migrations for the `tapix_imports` and `tapix_failed_import_rows` tables. With `tapix/livewire` it also publishes the Filament JS/CSS assets the wizard needs (action modals, etc.), so you don't need a Filament panel installed.
  :::

  :::tab{label="Core"}
  `tapix/core` has no installer. Its migrations are loaded automatically, so just run them:

  ```bash [Terminal]
  php artisan migrate
  ```
  :::
:::

### Keep assets in sync across updates

For `tapix/livewire` and `tapix/inertia`, add `tapix:upgrade` to your app's `composer.json` so assets and caches stay fresh on every `composer install` / `update` / `require`:

```json [composer.json]
"scripts": {
    "post-autoload-dump": [
        "Illuminate\\Foundation\\ComposerScripts::postAutoloadDump",
        "@php artisan package:discover --ansi",
        "@php artisan tapix:upgrade --ansi"
    ]
}
```

This mirrors Filament's own convention for `filament:upgrade` and is the recommended setup for all Tapix UI apps. `tapix/core` alone does not ship this command.

### Run a queue worker

Validation and execution run as [batched queue jobs](https://laravel.com/docs/queues#job-batching). Without a running worker, imports never finish validating or importing.

```bash [Terminal]
php artisan queue:work
```

Batching needs the `job_batches` table. New Laravel 12 apps already have it. If yours doesn't, create it:

```bash [Terminal]
php artisan make:queue-batches-table
php artisan migrate
```

### Create the notifications table

Tapix notifies the user when an import finishes, using Laravel's database notifications. Create the `notifications` table if your app doesn't have one yet:

```bash [Terminal]
php artisan make:notifications-table
php artisan migrate
```

Without it, imports are marked failed even though their rows were saved. If you don't want notifications, set `notifications.enabled` to `false` in `config/tapix.php` instead. See [Notifications](/features/notifications).

See [Queue Processing](/features/queue-processing) for dedicated queues and timeouts, and [Troubleshooting](/advanced/troubleshooting) if imports don't progress.

::

Once installation is complete, head to the [Quickstart](/getting-started/quickstart) guide to create your first importer and run your first import.
